# 🇬🇧 ClearEng — Telegram Mini App

Современное веб-приложение для изучения английского языка в формате **Telegram Mini App** с геймификацией в стиле **Duolingo** и **Busuu**.

## ✨ Возможности и функционал ClearEng

- 🗺️ **Интерактивная карта (14 дней):** вертикальная змейка с чекпоинтами недель (Неделя 1: глагол `to be`, Неделя 2: активные действия `Present Simple`).
- 📖 **Карточки теории:** наглядные правила, формулы-шпаргалки и живые примеры с озвучкой.
- 🔊 **Словарь дня:** транскрипция, перевод, примеры и аудио-произношение через Web Speech API.
- 🧩 **Интерактивная практика:**
  - Тесты с 4 вариантами ответов (Quiz).
  - Сборка предложений из плашек-слов (Sentence Builder).
  - Кнопка «💡 Подсказка» на каждом задании.
  - Умная система работы над ошибками (повтор ошибочных вопросов).
- 🟢/🔴 **Шторка обратной связи (Feedback Drawer):** анимация успеха или подробный разбор грамматической ошибки на русском языке.
- 🎮 **Геймификация:**
  - 🔥 Честный ударный режим (стрик) по реальным календарным дням с правильным склонением (`getDaysPlural`).
  - ❤️ 5 жизней со списанием за ошибки и экраном Game Over при потере всех сердечек.
  - ⭐ Начисление XP за первое прохождение дней.
- 🌙 **Тёмная и светлая тема:** поддержка комфортной ночной палитры с мгновенным переключением.
- 📱 **Нижняя панель навигации (3 вкладки):** «Обучение», «Профиль» со статистикой точности и «PRO» с оплатой в **Telegram Stars ⭐**.
- 🚀 **Интеграция с Telegram WebApp:** скрипт `telegram-web-app.js`, вызовы `ready()`, `expand()`, подтягивание имени пользователя и адаптация цвета хедера.

## 🛠️ Стек технологий

- **Фреймворк:** React 18 + Vite 5
- **Стилизация:** Tailwind CSS + PostCSS
- **Иконки:** Lucide React
- **Анимации и эффекты:** Canvas Confetti, кастомные Tailwind keyframes
- **Звук / Синтез речи:** Browser Web Speech API (`SpeechSynthesisUtterance`)
- **SDK:** Telegram WebApp JS SDK

## 🚀 Быстрый запуск

### 1. Установка зависимостей:
```bash
pnpm install
# или
npm install
```

### 2. Запуск локального сервера разработки:
```bash
pnpm run dev
# или
npm run dev
```
Откройте в браузере: **http://127.0.0.1:5173**

### 3. Сборка для продакшена:
```bash
pnpm run build
```
Готовые статические файлы будут находиться в папке `dist/`.
